Frequently Asked Questions (OpenAPI Diff & Breaking Change Gates)

Does API Drift Sentinel upload my OpenAPI or Swagger specifications to external servers?

No. Specification parsing, internal $ref resolution, and AST diffing execute strictly inside your local browser memory with zero backend upload and zero third-party network requests.

Which OpenAPI versions and breaking change rules are checked?

API Drift Sentinel supports OpenAPI 3.0, OpenAPI 3.1 (including type-null union equivalence), and Swagger 2.0 in JSON or YAML 1.2. It checks removed paths and methods, security schemes, request/response media types, asymmetric enum mutations, allOf/oneOf/anyOf composition, and readOnly/writeOnly rules.
