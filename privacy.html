Privacy & Legal Notice — API Drift Sentinel

API Drift Sentinel is an independent OpenAPI and Swagger semantic diff workbench operating in 0€ Validation Mode (no paid checkout, no user accounts, no payment processing).

1. Strict Local Execution & Zero Uploads

  • All OpenAPI 3.0, 3.1, and Swagger 2.0 specifications pasted or loaded into the workbench are parsed strictly inside local browser memory and never leave your machine.
  • No specification schemas, API keys, endpoints, or reports are transmitted to Conversionlogic servers or persisted in localStorage.
  • No analytics trackers, external CDNs, or tracking cookies are loaded.

2. Priority Waitlist Data (GDPR Art. 6(1)(a))

Joining the Multi-File $ref Bundler & CI Toolkit waitlist is strictly optional and requires checking an un-ticked consent box. Your email address and optional workflow preference are used solely for a one-time notification if API Drift Sentinel Pro launches. You may request removal at any time.

3. Informational Engineering Scope

Compatibility classifications (BREAKING, NON_BREAKING, INFO) implement deterministic AST checks across supported OpenAPI/Swagger constructs. Organizations remain responsible for integration tests and deployment approvals in their own pipelines.
